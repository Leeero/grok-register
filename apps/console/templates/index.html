System Settings

系统默认配置

这里保存全局默认值。新建任务时如果不展开高级设置，就直接使用这里的配置。

📬 LuckMail 配置说明
邮箱 API Base：留空即可（默认 https://mails.luckyous.com）
邮箱管理口令：填写你的 LuckMail X-API-Key（在 mails.luckyous.com → 用户中心 → API Key 页面获取）
邮箱域名：填写 LuckMail 项目编码，如 xai（对应 x.ai / Grok）；留空自动选首个可用项目
📫 DuckMail 配置说明
邮箱 API Base：留空即可（默认 https://api.duckmail.sbs），自建实例填实例地址
邮箱管理口令：填写你的 DuckMail API Key（格式：dk_xxx，在 domain.duckmail.sbs 获取）；使用私有域名时必填
邮箱域名：填写你的私有域名（如 example.com）；留空时优先自动选取私有域名，否则选公开域名
